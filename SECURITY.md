# Security Policy

## Supported Versions
We take security seriously. The following versions of NanoGPS are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| v1.x.x  | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within NanoGPS, please report it responsibly. Do not create public GitHub issues for security vulnerabilities. Instead, please report via direct contact or open a private advisory on the repository. All security reports will be promptly addressed.
