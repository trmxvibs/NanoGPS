# Changelog

All notable changes to NanoGPS will be documented in this file.

## [1.0] - 2026-09-08
### Added
- Dynamic Brand Template Cloner with integrated username input capture.
- Deep device telemetry (Storage quota, Client hints, Screen orientation).
- Compulsory localhost link option for all tunneling configurations.
- GitHub Actions CI workflow for automated syntax and requirement checks.

### Fixed
- f-string single brace escaping syntax errors in dynamic templates.
- Terminal output formatting for GPS and device fingerprint attributes.
