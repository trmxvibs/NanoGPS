# Contributing to NanoGPS

Thank you for your interest in contributing to NanoGPS! Whether it's bug fixes, new features, documentation, or feedback, contributions are always welcome.

## How to Contribute
1. Fork the repository (`https://github.com/trmxvibs/NanoGPS`).
2. Create your feature branch (`git checkout -b feature/AmazingFeature`).
3. Commit your changes (`git commit -m 'Add some AmazingFeature'`).
4. Push to the branch (`git push origin feature/AmazingFeature`).
5. Open a Pull Request.

Please make sure your code passes existing checks and follows the project's modular architecture.
